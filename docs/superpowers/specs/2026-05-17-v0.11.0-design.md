# rhino_mcp v0.11.0 — Feature Parity & Platform Design

> **For agentic workers:** This spec has three independent work streams (A, B, C). Each stream produces working, shippable software on its own. Implement them in order A → B → C. Use `superpowers:subagent-driven-development` to execute the implementation plan.

**Goal:** Close the feature gap with mcneel/rhinomcp while preserving rhino_mcp's unique depth — adding GH2 support, multi-Rhino slot management with auto-launch, and streamlined PackageManager distribution.

**Version:** 0.11.0

**Architecture overview:** Three independent work streams. Stream A is purely additive (new C# handlers + Python tools). Stream B is architectural (slot discovery + routing). Stream C is ops/tooling. All three can be built and shipped independently.

## Work Stream A — GH2 Support + RhinoInside Detection

### A1. Grasshopper 2 Tools

**Goal:** 11 GH2 MCP tools with `gh2_` prefix, mirroring GH1 coverage with the GH2 API. All tools degrade gracefully when GH2 is not installed.

#### Files

- Create: `rhino_plugin/RhinoMCPPlugin/GH2Handlers.cs`
- Create: `src/rhmcp/tools/gh2.py`
- Modify: `rhino_plugin/RhinoMCPPlugin/CommandDispatcher.cs` — add `gh2_*` dispatch cases + read-only list
- Modify: `rhino_plugin/RhinoMCPPlugin/RhinoMCPPlugin.csproj` — conditional GH2 reference

#### GH2 API Notes

GH2 (`Grasshopper2.dll`) ships with Rhino 8 but is not on NuGet. Reference it as a local hint-path assembly (same pattern used for RhinoCommon in plugins):

```xml
<ItemGroup Condition="Exists('$(RhinoPluginPath)/Grasshopper2.dll')">
  <Reference Include="Grasshopper2">
    <HintPath>$(RhinoPluginPath)/Grasshopper2.dll</HintPath>
    <Private>false</Private>
  </Reference>
</ItemGroup>
```

All GH2 handler code must be wrapped in try/catch. If GH2 is absent at runtime, return:
```json
{"ok": false, "error": "Grasshopper 2 is not available in this Rhino installation."}
```

Use the `Grasshopper2.Document` namespace for document access. GH2 uses `IGH2_Document`, `IGH2_Component`, `IGH2_Param` interfaces — check against the actual DLL at build time.

#### The 11 GH2 Tools

| Command type | MCP tool name | Description |
|---|---|---|
| `gh2_start` | `gh2_start` | Start Grasshopper 2 (calls `RhinoApp.RunScript("_Grasshopper2", false)`) |
| `gh2_get_canvas_graph` | `gh2_get_canvas_graph` | Full canvas snapshot: components, params, wires, volatile data (3-item sample per output) |
| `gh2_apply_graph` | `gh2_apply_graph` | Atomic: place components + sliders + wire all in one call; returns key→instanceGuid map |
| `gh2_place_component` | `gh2_place_component` | Place by GUID (preferred) or name; returns ambiguity candidates on name collision |
| `gh2_place_slider` | `gh2_place_slider` | Place Number Slider with min/max/value/decimals |
| `gh2_connect` | `gh2_connect` | Wire single output→input; accepts numeric index or param name |
| `gh2_connect_many` | `gh2_connect_many` | Batch wiring; continues past individual failures |
| `gh2_describe_component` | `gh2_describe_component` | Category, description, all input/output param names and types |
| `gh2_search_components` | `gh2_search_components` | Substring search against Name/NickName/Description; category/subcategory filters |
| `gh2_solve_graph` | `gh2_solve_graph` | Expire + re-solve canvas; returns error list |
| `gh2_clear_canvas` | `gh2_clear_canvas` | Clear all objects; requires `confirm: true` |

#### `gh2_apply_graph` — Atomic Graph Application (key feature)

This is the most valuable GH2 tool. It accepts a declarative graph description and applies it atomically:

```json
{
  "components": [
    {"key": "A", "type_name": "Point", "x": 100, "y": 100},
    {"key": "slider1", "type": "slider", "min": 0, "max": 10, "value": 5, "x": 0, "y": 100}
  ],
  "wires": [
    {"from_key": "slider1", "from_output": 0, "to_key": "A", "to_input": 0}
  ]
}
```

Returns:
```json
{
  "ok": true,
  "placed": {"A": "guid-...", "slider1": "guid-..."},
  "wired": 1,
  "errors": []
}
```

Partial failures (component not found, wire mismatch) are collected in `errors` — the call does not abort.

#### `gh2_get_canvas_graph` — Data Inspection

Returns per-output volatile data summary (configurable sample size, default 3 items):

```json
{
  "components": [
    {
      "instance_guid": "...",
      "name": "Circle",
      "type_guid": "...",
      "x": 200, "y": 150,
      "inputs": [{"name": "P", "type": "Point", "sources": []}],
      "outputs": [
        {
          "name": "C",
          "type": "Circle",
          "data_sample": ["Circle at (0,0,0) r=5", "Circle at (1,0,0) r=5"],
          "branch_count": 1,
          "item_count": 2
        }
      ],
      "messages": [],
      "display_summary": "2 circles"
    }
  ],
  "wires": [{"from_instance": "...", "from_output": 0, "to_instance": "...", "to_input": 0}]
}
```

#### Python module (`src/rhmcp/tools/gh2.py`)

Single module, all 11 tools in one `register(mcp)` function. Each tool follows the same thin-wrapper pattern as existing GH1 tools — build params dict, call `_gh2("gh2_command_type", params)` helper that routes to plugin socket.

```python
def _gh2(command: str, params: dict) -> dict:
    return rhino.plugin_result(command, params)
```

All tools have `rhino_id: str | None = None` parameter (passed through to backend).

## Work Stream B — Multi-Rhino Slot Management + Auto-Launch

### B1. Announcement Protocol (C# Plugin)

**Goal:** Each running Rhino plugin instance writes a discovery file when the TCP server starts, deletes it when the server stops. Python reads these files to discover live instances.

#### Files

- Create: `rhino_plugin/RhinoMCPPlugin/SlotAnnouncer.cs`
- Modify: `rhino_plugin/RhinoMCPPlugin/RhinoMcpServer.cs` — call announcer on start/stop

#### Announcement File Location

| Platform | Path |
|---|---|
| macOS / Linux | `/tmp/rhino-mcp-slots/{pid}.json` |
| Windows | `%TEMP%\rhino-mcp-slots\{pid}.json` |

Directory is created if absent. File is deleted on server stop or plugin shutdown.

#### File Format

```json
{
  "pid": 12345,
  "host": "127.0.0.1",
  "port": 1999,
  "version": "0.11.0",
  "rhino_version": "8.31.26126.13432",
  "started_at": "2026-05-17T01:23:45Z"
}
```

`pid` is the integer process ID. This is also the `rhino_id` used by Python tools.

#### `SlotAnnouncer.cs`

```csharp
public static class SlotAnnouncer
{
    private static string? _announcePath;

    public static void Announce(string host, int port, string version)
    {
        var dir = SlotsDirectory();
        Directory.CreateDirectory(dir);
        var pid = Environment.ProcessId;
        _announcePath = Path.Combine(dir, $"{pid}.json");
        var payload = JsonSerializer.Serialize(new {
            pid, host, port, version,
            rhino_version = RhinoApp.Version.ToString(),
            started_at = DateTime.UtcNow.ToString("o")
        });
        File.WriteAllText(_announcePath, payload);
    }

    public static void Withdraw()
    {
        if (_announcePath != null && File.Exists(_announcePath))
            File.Delete(_announcePath);
        _announcePath = null;
    }

    private static string SlotsDirectory()
    {
        var tmp = Path.GetTempPath();
        return Path.Combine(tmp, "rhino-mcp-slots");
    }
}
```

`RhinoMcpServer.Start()` calls `SlotAnnouncer.Announce(...)` after the listener is running. `RhinoMcpServer.Stop()` calls `SlotAnnouncer.Withdraw()`.

### B2. Slot Registry (Python)

**Goal:** Python-side discovery of live Rhino instances. Routes plugin socket commands to the correct Rhino process.

#### Files

- Create: `src/rhmcp/tools_helpers/slot_registry.py`
- Modify: `src/rhmcp/tools_helpers/backend.py` — wire `rhino_id` → slot registry
- Modify: `src/rhmcp/tools_helpers/plugin_client.py` — accept `rhino_id` in `send_command()`
- Create: `tests/test_slot_registry.py`

#### `slot_registry.py`

```python
from __future__ import annotations
import json
import os
import sys
from dataclasses import dataclass
from pathlib import Path
from typing import Iterator

@dataclass(frozen=True)
class SlotInfo:
    pid: int
    host: str
    port: int
    version: str
    rhino_version: str
    started_at: str

    @property
    def rhino_id(self) -> str:
        return str(self.pid)

def _slots_dir() -> Path:
    if sys.platform == "win32":
        base = Path(os.environ.get("TEMP", "C:/Temp"))
    else:
        base = Path("/tmp")
    return base / "rhino-mcp-slots"

def _is_alive(pid: int) -> bool:
    try:
        os.kill(pid, 0)   # signal 0 = existence check
        return True
    except OSError:
        return False

def discover() -> dict[str, SlotInfo]:
    """Return all live slots keyed by rhino_id (str(pid))."""
    slots: dict[str, SlotInfo] = {}
    d = _slots_dir()
    if not d.exists():
        return slots
    for f in d.glob("*.json"):
        try:
            data = json.loads(f.read_text())
            pid = int(data["pid"])
            if not _is_alive(pid):
                f.unlink(missing_ok=True)   # prune stale
                continue
            info = SlotInfo(
                pid=pid,
                host=data["host"],
                port=int(data["port"]),
                version=data.get("version", ""),
                rhino_version=data.get("rhino_version", ""),
                started_at=data.get("started_at", ""),
            )
            slots[str(pid)] = info
        except Exception:
            continue
    return slots

def get(rhino_id: str | None = None) -> SlotInfo:
    """
    Resolve rhino_id to a SlotInfo.
    None → first available slot (backward compat with single-instance setups).
    Raises RuntimeError if no matching slot found.
    """
    slots = discover()
    if not slots:
        raise RuntimeError(
            "No live Rhino MCP plugin slots found. "
            "Start Rhino and run MCPStart, or call launch_rhino first."
        )
    if rhino_id is None:
        return next(iter(slots.values()))
    if rhino_id not in slots:
        raise RuntimeError(
            f"Rhino slot '{rhino_id}' not found. "
            f"Available: {list(slots.keys())}"
        )
    return slots[rhino_id]

def wait_for_slot(pid: int, timeout: float = 30.0, poll: float = 0.5) -> SlotInfo:
    """Poll until the given PID appears in the slot registry."""
    import time
    deadline = time.monotonic() + timeout
    while time.monotonic() < deadline:
        slots = discover()
        if str(pid) in slots:
            return slots[str(pid)]
        time.sleep(poll)
    raise TimeoutError(f"Rhino process {pid} did not announce within {timeout}s")
```

#### Backend Routing (`backend.py`)

`plugin_result()` currently calls `plugin_client.send_command()` with fixed host/port from env vars. Update to resolve via slot registry when `rhino_id` is provided:

```python
def plugin_result(
    command_type: str,
    params: dict[str, Any] | None = None,
    rhino_id: str | None = None,
) -> dict[str, Any]:
    # Resolve connection target
    host = port = None
    if rhino_id is not None or _slot_registry_enabled():
        try:
            from rhmcp.tools_helpers import slot_registry
            slot = slot_registry.get(rhino_id)
            host, port = slot.host, slot.port
        except RuntimeError:
            pass  # fall through to env-var defaults (backward compat)
    response = plugin_client.send_command(command_type, params, host=host, port=port)
    ...
```

`_slot_registry_enabled()` returns True when `RHINO_MCP_USE_SLOT_REGISTRY=1` (opt-in env var) or when `rhino_id` is explicitly passed. This preserves zero-config behavior for existing single-instance users.

#### `plugin_client.send_command()` — add `rhino_id`

Already accepts `host` and `port` overrides. No change needed to the signature — routing is resolved in `backend.py` before calling `send_command`.

### B3. Auto-Launch (`rhino_launcher.py`)

**Goal:** Detect the Rhino installation and spawn a Rhino process. Wait for it to announce itself in the slot registry.

#### Files

- Create: `src/rhmcp/tools_helpers/rhino_launcher.py`
- Create: `src/rhmcp/tools/slots.py` — MCP tools: `get_rhino_instances`, `launch_rhino`
- Create: `tests/test_rhino_launcher.py`

#### `rhino_launcher.py`

```python
from __future__ import annotations
import os
import subprocess
import sys
from pathlib import Path

# Ordered by preference (newest first)
_RHINO_PATHS: dict[str, list[str]] = {
    "darwin": [
        "/Applications/Rhino 8.app/Contents/MacOS/Rhino",
        "/Applications/Rhino 7.app/Contents/MacOS/Rhino",
    ],
    "win32": [
        r"C:\Program Files\Rhino 8\System\Rhino.exe",
        r"C:\Program Files\Rhino 7\System\Rhino.exe",
    ],
    "linux": [],  # RhinoInside/Compute only
}

def find_rhino() -> Path | None:
    """Return path to Rhino executable, or None if not found."""
    override = os.environ.get("RHINO_MCP_RHINO_PATH")
    if override:
        p = Path(override)
        return p if p.exists() else None
    for candidate in _RHINO_PATHS.get(sys.platform, []):
        p = Path(candidate)
        if p.exists():
            return p
    return None

def launch(rhino_path: Path | None = None, timeout: float = 60.0) -> int:
    """
    Launch Rhino and wait for its MCP plugin to announce itself.
    Returns the PID of the new Rhino process.
    Raises RuntimeError if Rhino not found; TimeoutError if plugin doesn't start.
    """
    from rhmcp.tools_helpers import slot_registry

    exe = rhino_path or find_rhino()
    if exe is None:
        raise RuntimeError(
            "Rhino executable not found. "
            "Set RHINO_MCP_RHINO_PATH or install Rhino to a standard location."
        )

    proc = subprocess.Popen(
        [str(exe)],
        stdout=subprocess.DEVNULL,
        stderr=subprocess.DEVNULL,
        start_new_session=True,
    )
    slot_registry.wait_for_slot(proc.pid, timeout=timeout)
    return proc.pid
```

#### MCP Tools (`src/rhmcp/tools/slots.py`)

```python
def register(mcp: FastMCP) -> None:

    @mcp.tool(annotations=ToolAnnotations(title="List Rhino Instances", readOnlyHint=True))
    def get_rhino_instances() -> dict:
        """
        Return all live Rhino instances with MCP plugin running.
        Each entry has rhino_id, host, port, version, rhino_version.
        Pass rhino_id to any tool to target a specific instance.
        """
        from rhmcp.tools_helpers import slot_registry
        slots = slot_registry.discover()
        return {
            "ok": True,
            "instances": [
                {"rhino_id": s.rhino_id, "host": s.host, "port": s.port,
                 "version": s.version, "rhino_version": s.rhino_version,
                 "started_at": s.started_at}
                for s in slots.values()
            ],
            "count": len(slots),
        }

    @mcp.tool(annotations=ToolAnnotations(title="Launch Rhino"))
    def launch_rhino(
        rhino_path: str | None = None,
        timeout: float | None = None,
    ) -> dict:
        """
        Launch a new Rhino instance and wait for MCP plugin to start.
        Returns rhino_id to use with other tools.

        rhino_path: Optional override path to Rhino executable.
        timeout: Seconds to wait for plugin startup (default 60).
        """
        from rhmcp.tools_helpers import rhino_launcher
        t = timeout or 60.0
        path = Path(rhino_path) if rhino_path else None
        try:
            pid = rhino_launcher.launch(path, timeout=t)
            return {"ok": True, "rhino_id": str(pid), "pid": pid}
        except (RuntimeError, TimeoutError) as ex:
            return {"ok": False, "error": str(ex)}
```

## Open Questions / Risks

1. **GH2 assembly path**: `Grasshopper2.dll` ships inside Rhino 8 but the exact path varies by install and OS. The csproj `HintPath` must be tested on both macOS and Windows. If the DLL is not found at build time, GH2 support is skipped gracefully — the Python tools still register but return the "not available" error.

2. **`RHINO_MCP_USE_SLOT_REGISTRY` opt-in**: Existing single-Rhino users should see zero behavior change. The slot registry is only consulted when a `rhino_id` is explicitly passed, OR when the opt-in env var is set. Default path remains env-var-based direct connection.

3. **Windows `os.kill(pid, 0)`**: On Windows, `os.kill(pid, 0)` raises `OSError` for any error including "process exists but access denied." The fallback is `psutil.pid_exists()` if available, else assume alive and let the socket timeout be the dead-instance detector.

4. **Yak publishing account**: McNeel approval may take a few days for a new publisher. Document the steps but don't block the release on it.
