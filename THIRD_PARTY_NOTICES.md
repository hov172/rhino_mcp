# Third-party components

The MIT license in `LICENSE` applies to rhino-mcp's own code. Dependencies and
native libraries retain their respective licenses and notices.

The PDF implementation uses pypdfium2/PDFium, pdfplumber/pdfminer.six, Pillow,
and psutil. PyMuPDF/MuPDF is not a dependency in 0.18.0. The pypdfium2 wheel
contains build-specific PDFium dependency notices, which must be retained with
binary distributions. pdfplumber and pdfminer.six use MIT; psutil uses BSD-3-Clause.
See the installed distributions for the exact license texts and versions.

The universal installer includes `/Users/Shared/rhino_mcp/third-party/` with
per-architecture inventories, CycloneDX Python component lists, collected license
files, hashed dependency requirements, and native Intel cryptography/OpenSSL
build provenance. Docker includes `/app/third-party/`. Python wheel installation
also installs dependency distributions containing their own notices; the project
wheel does not bundle all those dependencies inside itself.

These inventories are generated by `scripts/dependency-inventory.py` from the
runtime being packaged. They include PDFium's bundled license files but are not
a complete native binary dependency graph or a legal compliance certification.
Review the complete distribution's licenses for the intended use, and preserve
notices when redistributing or repackaging. Earlier release obligations are not
changed by replacing a dependency in a later version.
