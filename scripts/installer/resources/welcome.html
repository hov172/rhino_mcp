Rhino MCP

This installer will:

  • Install the Rhino MCP server to /Users/Shared/rhino_mcp/ (accessible by all users)
  • Install the Rhino 8 plug-in to each user’s Rhinoceros folder on first login
  • Configure Claude Desktop, Claude Code, ChatGPT Desktop, and Codex (if installed)

Requirements: macOS 13 Ventura or later · Apple Silicon or Intel (universal) · Admin password

After installation, open Rhino 8 and run the MCPStart command, then restart your AI client.

Additional users on this machine will be configured automatically on their next login.
